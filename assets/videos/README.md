# Add your videos here

Copy video clips into this folder, for example:
- video-01.mp4
- birthday-clip.webm

Then add an entry to `memories` in `js/config.js`:
`{ id: "clip-01", type: "video", src: "assets/videos/video-01.mp4", caption: "A favorite moment", date: "" }`

MP4 with H.264 video is a good compatibility choice. Videos use native controls and are not autoplayed.
