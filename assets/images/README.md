# Add your photos here

Copy your edited images into this folder, for example:
- photo-01.jpg
- photo-02.png
- birthday-edit.webp

Then open `js/config.js` and add entries to `memories` and/or `galleryImages` using paths such as:
`assets/images/photo-01.jpg`

Supported browser formats usually include JPG/JPEG, PNG, WebP, GIF, and AVIF. For best performance, resize very large images before adding them.
